# 3WD-VLA Workflow And Function Map

## 1. End-to-End Workflow (Main Path)

### Entry scripts
- Linux one-click: `run_all.sh`
- Windows one-click: `run_all.bat`
- Offline one-click: `run_all_offline.sh`
- Offline evaluation: `run_eval_offline.sh`
- Selector-only: `run_selector.sh`
- 3DW pipeline: `run_3dw.sh`
- Single-step brain decision: `run_brain_decision.sh`
- Single config: `config.sh`

### Runtime chain
1. Launch image receiver/viewer.
   - Script: `share/share_viewer.py`
   - Function: `start_viewer()`
   - Output:
     - latest merged image: `brain_ready.jpg`
     - archived merged images: `combined_N.jpg`
2. Launch pipeline orchestrator.
   - Script: `bigbrain/pipeline_runner.py`
   - Function: `main()`
3. Build supervisor brain instance.
   - Script: `bigbrain/pipeline_runner.py`
   - Function: `build_supervisor(args)`
   - Calls class: `supervisor_brain/supervisor_core.py::SupervisorCore`
4. Perform first negative-domain check (safety/target/light).
   - Script: `bigbrain/pipeline_runner.py`
   - Function: `run_supervisor_once(core, image_path)`
   - Internals:
     - `SupervisorCore.vlm_reasoning(...)`
     - `SupervisorCore.decide(...)`
5. Branch by mode:
   - `sequential`: `run_sequential(args)`  
     loops BigBrain decisions until action enters positive domain.
   - `selector`: `run_selector(args)`  
     one-shot analysis and action sequence.
   - `3dw`: `run_3dw(args)`  
     pairwise comparison + math model -> positive/boundary.
6. Send command to robot if command exists.
   - Script: `bigbrain/pipeline_runner.py`
   - Function: `maybe_send_robot(...)`
   - Calls class method: `supervisor_brain/robot_client.py::RobotClient.send(...)`
7. Persist outputs.
   - Action code file: `write_action(...)`
   - JSON result log: `main()` tail section in `pipeline_runner.py`

## 2. Mode Behavior

### `sequential` mode
- First pass supervisor check.
- Then repeatedly:
  - read latest image,
  - optional periodic supervisor check every `--supervisor_interval_sec`,
  - call BigBrain one-step decision (`BigBrainDecisionEngine.infer_action`),
  - write action to `out_action_file`,
  - stop when action is in positive set:
    - `GRASP_STANDARD`
    - `GRASP_LEFT_TARGET`
    - `GRASP_RIGHT_TARGET`
    - `GRASP_BOTTOM`
    - `GRASP_VERTICAL`

### `selector` mode
- First pass supervisor check.
- One-shot selector inference:
  - script: `bigbrain/selector.py`
  - function: `analyze_image_and_select(...)`
- Returns action list and executes/sends actions in order.
- Runs a background supervisor loop every `--supervisor_loop_interval_sec` to enforce stop/slowdown during execution.
- If action list contains `REQ_USER_SELECT` and `--interactive_select` is enabled, terminal prompts for `left/right` and resolves to `GRASP_LEFT_TARGET` or `GRASP_RIGHT_TARGET`.

### `3dw` mode
- First pass supervisor check.
- Pairwise comparison is generated by LoRA model.
- `3dw.py::calculate_alpha_only(...)` computes alpha.
- If `positive`: map to a direct grasp action.
- If `boundary`: fall back to selector path.
- Runs a background supervisor loop every `--supervisor_loop_interval_sec` to enforce stop/slowdown during execution.
- If selector fallback returns `REQ_USER_SELECT` and `--interactive_select` is enabled, terminal prompts for `left/right` and resolves to `GRASP_LEFT_TARGET` or `GRASP_RIGHT_TARGET`.

## 2.1 Supervisor State Table

| State | Condition (from `vision_data`) | Robot Command | Purpose |
|---|---|---|---|
| `NEGATIVE_1` | `hand_detected == True` | `ALARM_TRIGGERED` | Emergency stop on human hand detection |
| `NEGATIVE_2` | `target_missing == True` | `None` | Abort when target not in view |
| `BOUNDARY` | `is_lighting_dim == True` | `SET_SPEED_RATIO 0.3` | Slow down under low light |
| `POSITIVE` | none of the above | `SET_SPEED_RATIO 1.0` | Normal speed |

Notes:
- Source: `supervisor_brain/supervisor_core.py::SupervisorCore.decide`
- The loop runs independently every `--supervisor_loop_interval_sec`.

## 3. Function-Level Responsibilities (By Script)

## `run_all.sh`
- Variable block: central config for whole run.
- Viewer launch block: runs `share/share_viewer.py` in background.
- Cleanup trap: kills viewer process on exit.
- Pipeline launch block: calls `bigbrain/pipeline_runner.py` with shared args.

## `run_all.bat`
- Same purpose as `run_all.sh` on Windows.
- Uses `start` to open viewer in new cmd window.

## `share/share_viewer.py`
- `stitch_images(top_img, hand_img)`:
  - resizes top and hand frames to fixed target height,
  - stitches as `Top | Separator | Hand`.
- `start_viewer()`:
  - listens UDP packets,
  - caches `H`(hand) and `T`(top),
  - when a pair is ready, calls `stitch_images`,
  - writes `brain_ready.jpg` and `combined_N.jpg`.

## `bigbrain/pipeline_runner.py`
- `latest_image(path)`:
  - returns newest image file in monitor directory.
- `wait_for_latest_image(monitor_dir, timeout_sec)`:
  - waits until an image exists or timeout.
- `write_action(action_code, out_file)`:
  - writes current action code for downstream pollers.
- `BigBrainDecisionEngine.__init__(...)`:
  - stores model generation parameters and loads model.
- `BigBrainDecisionEngine._load_model()`:
  - loads base VLM + LoRA adapter.
- `BigBrainDecisionEngine.infer_action(image_path)`:
  - runs one-step decision,
  - extracts valid action code,
  - maps to robot/ui instruction.
- `maybe_send_robot(robot_client, cmd, meta, dry_run)`:
  - sends command unless `dry_run` or missing client.
- `run_supervisor_once(core, image_path)`:
  - calls supervisor reasoning and decision.
- `build_supervisor(args)`:
  - builds `SupervisorCore` using backend `api/local`.
- `start_supervisor_loop(...)`:
  - background safety loop, interval `--supervisor_loop_interval_sec`.
- `run_sequential(args)`:
  - complete sequential workflow orchestration.
- `run_selector(args)`:
  - complete selector workflow orchestration.
- `run_3dw(args)`:
  - pairwise + 3DW math + boundary fallback to selector.
- `build_parser()`:
  - CLI argument definitions.
- `main()`:
  - entrypoint, mode routing, JSON log write.

## `supervisor_brain/supervisor_core.py`
- `SupervisorCore.__init__(...)`:
  - backend selection (`api` or `local`),
  - local model lazy init trigger.
- `SupervisorCore._init_local_model()`:
  - loads local processor/model (+ optional lora).
- `SupervisorCore.encode_image(image_path)`:
  - base64 encoding for API backend.
- `SupervisorCore._extract_text(content)`:
  - strips markdown wrappers from model output.
- `SupervisorCore._call_vlm_api(image_path, prompt)`:
  - sends OpenAI-compatible VLM HTTP request.
- `SupervisorCore._call_vlm_local(image_path, prompt)`:
  - local VLM inference on merged image.
- `SupervisorCore.call_vlm(image_path, prompt)`:
  - backend switch.
- `SupervisorCore.vlm_reasoning(img_path)`:
  - asks 3 safety questions and parses JSON.
- `SupervisorCore.decide(vision_data)`:
  - maps booleans to state + robot speed/alert command.

## `supervisor_brain/robot_client.py`
- `RobotClient.__init__(robot_url, timeout)`:
  - stores robot endpoint config.
- `RobotClient.send(cmd, meta)`:
  - posts command payload to robot API.

## `bigbrain/selector.py`
- `_build_prompt(instruction)`:
  - builds one-shot structured prompt.
- `analyze_image_and_select(vlm_call, image_path, user_instruction)`:
  - calls VLM,
  - parses JSON or fallback heuristic parse,
  - converts to action list by rule,
  - maps action to robot/ui via `InstructionRegistry`.

## `share/instruction_library.py`
- `ActionCodes`:
  - centralized action code constants.
- `InstructionRegistry.get_instruction(action_code, **kwargs)`:
  - maps action to robot command and UI text.
- `InstructionRegistry.get_brain_menu()`:
  - generates the action protocol text used in BigBrain prompting.

## 4. Supporting Scripts (Not in Main One-Click Path)

## `share/build_merged_dataset.py`
- Dataset offline utility.
- Builds merged images from paired `top/` and `hand/` folders.
- Main functions:
  - `stitch_images(...)`
  - `iter_classes(...)`
  - `main()`

## `bigbrain/brain_decision.py`
- Standalone one-step BigBrain decision utility.
- Core helper functions:
  - `load_py_module(...)`
  - `resolve_base_model_from_adapter(...)`
  - `is_lora_adapter_dir(...)`
  - `build_messages_for_action_select(...)`
  - `extract_action_code(...)`
  - `write_action_to_file(...)`
  - `main()`
- Current main orchestrator reuses some helpers from this file.

## `supervisor_brain/main_supervisor.py`
- Legacy standalone supervisor loop.
- Its role overlaps with `pipeline_runner.py` now.

## `bigbrain/3dw.py`
- Experimental script for alpha score based three-way decision from pairwise ranking text.
- Used by `pipeline_runner.py` when `--mode 3dw`.

## `bigbrain/export_lora_outputs_xlsx.py`
- Batch inference/export utility for dataset analysis.
- Not used by runtime workflow.

## 5. Can We Delete Unrelated Files?

Below is a conservative cleanup recommendation.

### Safe to delete for runtime deployment
- Windows Zone Identifier artifacts:
  - files ending with `:Zone.Identifier` (or similarly displayed suffixes in this repo).
- Python cache folders:
  - `**/__pycache__/`
- Local extracted test data if not needed on cloud:
  - `test_images_unzipped/`
- Local zip archives if already transferred:
  - `test——images.zip`
  - `lora_output.zip`

### Keep (required for main workflow)
- `run_all.sh` / `run_all.bat`
- `config.sh`
- `bigbrain/pipeline_runner.py`
- `share/share_viewer.py`
- `supervisor_brain/supervisor_core.py`
- `supervisor_brain/robot_client.py`
- `share/instruction_library.py`
- `bigbrain/selector.py`
- `bigbrain/brain_decision.py` (helper functions used by pipeline)
- model directory (e.g. `lora_output/`) unless you will mount another model path

### Optional to remove if you no longer need legacy/analysis scripts
- `supervisor_brain/main_supervisor.py`
- `bigbrain/3dw.py`
- `bigbrain/export_lora_outputs_xlsx.py`
